# Rumi — frontend (Vite, versión original)

Implementación original del frontend web de Rumi, hecha con Vite + React + TypeScript + `react-router-dom`.

Reemplazada por la app en [`../frontend`](../frontend), migrada a **Next.js** para poder tener un mini backend propio (API routes) dentro del mismo proyecto. Esta carpeta se conserva como referencia; mismo diseño y lógica, solo cambia el framework.

## Cómo correrla

```bash
cd frontend-vite
npm install
npm run dev
```
