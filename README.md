# Rumi

Rumi es un comunicador aumentativo basado en pictogramas, pensado para apoyar a niños autistas no verbales.

## Stack principal

- **Frontend:** React
- **API de pictogramas:** https://arasaac.org/
- **Modelo base de IA:** Gemma 4

## Objetivo

Crear una experiencia simple, accesible y visual que facilite la comunicación diaria mediante pictogramas y asistencia de IA.
