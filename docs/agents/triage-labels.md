# Triage Labels

Use these labels for the five canonical triage roles:

| Role | GitHub label |
| --- | --- |
| Needs triage | `needs-triage` |
| Needs information | `needs-info` |
| Ready for an agent | `ready-for-agent` |
| Ready for a human | `ready-for-human` |
| Won't fix | `wontfix` |

The labels should be created in GitHub before using the triage workflow if they do not already exist.
